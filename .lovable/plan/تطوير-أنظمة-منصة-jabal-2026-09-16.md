# تطوير أنظمة منصة JABAL

تطوير أربعة أنظمة أساسية على مراحل، مع الحفاظ على التصميم الحالي.

## 1. نظام الطلبات والدفع
- **حالات الطلب**: مسار واضح (بانتظار التأكيد → مؤكد → قيد التجهيز → بالطريق → تم التسليم → ملغي) مع شريط تتبع مرئي في صفحة الطلب.
- **إشعارات الحالة**: تسجيل كل تغيير في سجل التتبع مع الوقت والملاحظة.
- **إلغاء الطلب**: زر إلغاء للعميل ما دام الطلب لم يدخل مرحلة التجهيز.
- **كوبونات الخصم**: تفعيل التحقق من الكود عند الدفع (صلاحية، حد أدنى، عدد مرات الاستخدام).
- **فاتورة**: صفحة فاتورة قابلة للطباعة لكل طلب.
- **الدفع**: الإبقاء على الدفع عند التسليم + تحويل بنكي مع رفع إثبات الدفع. (الدفع الإلكتروني ببطاقة يحتاج قراراً منفصلاً منك.)

## 2. نظام الموردين والسوق
- **لوحة المورد**: صفحة خاصة يضيف فيها المورد منتجاته ويعدّل الأسعار والكميات وحالة التوفر.
- **بحث وفلترة أقوى** في السوق: فئة، سعر، منطقة، تقييم، توفر، ترتيب حسب الأقرب/الأرخص.
- **المخزون**: إنقاص الكمية عند الطلب ومنع الطلب عند نفاد الكمية.
- **عروض طلبات الأسعار (RFQ)**: استقبال عروض من عدة موردين ومقارنتها واختيار الأفضل.
- **تقييمات موثقة**: السماح بالتقييم فقط لمن اشترى المنتج فعلاً.

## 3. نظام المستخدمين والأمان
- **الأدوار**: عميل / مورد / مقاول / مدير، مع جدول أدوار مستقل وصلاحيات على مستوى قاعدة البيانات.
- **تحقق من رقم الهاتف**: بنية كود تحقق (OTP) جاهزة — إرسال عبر البريد الآن، وقابلة لتشغيل SMS لاحقاً عند ربط مزود.
- **منع الاحتيال**: حد لعدد المحاولات، منع تكرار نفس الرقم، وحجب الطلبات المشبوهة المتكررة.
- **صفحة حسابي**: بيانات، عناوين محفوظة، رقم موثق، وسجل النشاط.
- **لوحة إدارة**: مراجعة المستخدمين والطلبات والبلاغات وتوثيق الموردين.

## 4. نظام تسليم المفتاح والمعاينة
- **مراحل المشروع**: خط زمني بمراحل ونسبة إنجاز وصور تحديث من الموقع.
- **عروض المقاولين**: مقارنة العروض (السعر، المدة، التقييم) واختيار المقاول.
- **الدفعات**: جدول دفعات مرتبط بالمراحل مع حالة كل دفعة.
- **المعاينة الهندسية**: جدولة موعد، تعيين مهندس، وتقرير معاينة نهائي.

## الترتيب المقترح للتنفيذ
1. الأدوار والأمان وتحقق الهاتف (أساس لكل ما بعده)
2. الطلبات والدفع والكوبونات والفاتورة
3. لوحة المورد والمخزون والبحث المتقدم
4. المشاريع والمعاينة والدفعات
5. لوحة الإدارة

## ملاحظات تقنية
- إضافة/تعديل جداول: `user_roles`، `phone_verifications`، `order_tracking`، `project_updates`، `project_payments`، `contractor_bids`، مع سياسات وصول (RLS) وصلاحيات صريحة لكل جدول.
- منطق الخادم عبر server functions في TanStack Start؛ العمليات الحساسة (تطبيق الكوبون، تغيير حالة الطلب، إنشاء OTP) تتم على الخادم فقط.
- تحديد معدل الطلبات (rate limiting) على إنشاء OTP والتسجيل وإرسال النماذج.
